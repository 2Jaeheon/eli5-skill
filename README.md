# ELI5

어려운 개념과 절차를 쉬운 한국어로 설명하는 Codex 스킬입니다.
처음 읽는 사람이 핵심 뜻과 실제 동작을 이해할 수 있게 설명합니다.

## 설명 방식

- 핵심 답과 전체 흐름을 먼저 보여줍니다.
- 필요한 용어를 설명한 뒤 세부 내용을 순서대로 풀어 씁니다.
- 실제 대상, 동작, 결과와 상태 변화를 중심으로 설명합니다.
- 순서와 구조, 특징의 차이는 표 대신 Mermaid 다이어그램으로 보여줍니다.
- 단계별 설명에는 각 단계의 작은 다이어그램을 함께 넣습니다.
- 전문 용어의 정확성을 유지하고, 기본 분량은 중간 길이로 맞춥니다.
- 은유, 비유, 가운뎃점과 유니코드 연결 화살표 문자를 사용하지 않습니다.

## 사용 예시

스킬이 등록된 Codex에서 다음처럼 요청합니다.

```text
$eli5 DB 연결과 커넥션 풀이 실제로 어떻게 동작하는지 설명해줘.
```

```text
$eli5 이 코드가 실행될 때 값과 저장 상태가 어떻게 바뀌는지 설명해줘.
```

## 파일 구성

- `SKILL.md`: 설명 방식과 작성 후 확인 기준
- `agents/openai.yaml`: 스킬 표시 이름, 짧은 소개와 기본 요청문

현재 사용 중인 스킬 파일을 그대로 포함했습니다.
